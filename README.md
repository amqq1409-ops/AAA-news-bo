# Saudi News Watch

بوت يجمع الأخبار عن السعودية من GDELT وGoogle News، ويضيف إليها معلومات لغوية
وجغرافية وتصنيفاً موضوعياً قبل اختيار الأخبار وإرسالها.

## معالجة اللغة والمعلومات المستخرجة

- يكتشف أسماء الدول بالعربية والإنجليزية في العنوان ومقتطف RSS المتاح، ويخزن
  رمز الدولة واسمها وعلمها؛ لا يجلب البوت نص المقال الكامل.
- يستخرج الأشخاص والأماكن والمنظمات المعروفة، ويستخدم spaCy لاستخراج كيانات
  إضافية عند توفر النموذج.
- يحسّن اللغة المكتشفة باستخدام `langdetect`، مع الاحتفاظ بقائمة اللغات المرصودة.
- يصنف الموضوعات مع درجة `topic_confidence`، ويحسب `confidence_score` لمدى صلة
  العنوان بالسعودية. هذه الدرجات تقديرات آلية وليست تحققاً من صحة الخبر.
- يحفظ قيم الدول والكيانات واللغات بصيغة JSON في المقالة، كما ينشئ جداول
  مترابطة للدول والكيانات لتسهيل البحث. تتم ترقية قواعد SQLite القديمة تلقائياً.

## التثبيت والتشغيل

```bash
python -m pip install -r requirements.txt
python news_bot.py --dry-run
```

تعمل المعالجة الأساسية دون تنزيل نماذج تعلم آلي. لاستخدام spaCy، ثبّت نموذجاً
متوافقاً (مثلاً `en_core_web_sm`) واضبط `NEWS_SPACY_MODEL` على اسمه. لا ينزّل
البوت النماذج تلقائياً.

يمكن تفعيل تصنيف Hugging Face الاختياري بتثبيت backend مناسب لـ Transformers،
وتعيين `NEWS_ZERO_SHOT_MODEL` إلى اسم نموذج zero-shot أو مساره المحلي. لا يسمح
البوت بتشغيل كود مخصص من مستودع النموذج (`trust_remote_code=False`). إذا لم يتوفر
النموذج أو backend، يستمر باستخدام التصنيف الاحتياطي.

يحتاج الإرسال الفعلي إلى `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`. وفي غيابهما
يعمل البوت بوضع التجربة.
