# Saudi News Watch

بوت يجمع الأخبار التي تتناول السعودية من Google News وGDELT وRSS، ويمكنه استخدام NewsAPI وBing News Search عند توفر مفاتيح الوصول.

## الإعداد والتشغيل

1. ثبّت Python 3.12 أو أحدث، ثم نفّذ `pip install -r requirements.txt`.
2. عدّل `config.yaml` لتفعيل المصادر المطلوبة وإضافة أو حذف خلاصات RSS.
3. عيّن المفاتيح في البيئة، ولا تضعها في ملف الإعدادات أو المستودع:

   ```sh
   export NEWSAPI_API_KEY="..."
   export BING_NEWS_API_KEY="..."
   ```

4. عيّن متغيرات Telegram المعتادة، ثم شغّل `python news_bot.py`. استخدم `--dry-run` للتجربة دون إرسال.

المصدران المدفوعان اختياريان؛ عند تفعيلهما من دون مفتاح، يتخطاهما البوت ويسجل ذلك. يمكن تعديل أسماء متغيرات المفاتيح ونقاط النهاية من ملف الإعدادات. تُجلب المصادر بالتوازي، ويمكن ضبط عدد العمال عبر `source_workers`، وتظل مهلة التشغيل الكلية مضبوطة عبر `total_time_budget_sec`.

## التغطية والقيود

تُضاف الخلاصات من خلال `rss.feeds` مع `url` وبيانات اختيارية مثل `lang` و`country_ar`. الخلاصات المضمّنة أمثلة قابلة للتعديل، وقد تتغير عناوينها أو سياساتها. يمكن إضافة مئات الخلاصات ما دامت متاحة علناً.

توسّع المصادر التغطية لكنها لا تضمن كل دولة أو لغة أو خبر منشور. تعتمد النتائج على فهرسة كل مزود وتوفر خلاصاته، كما تخضع NewsAPI وBing للحساب والخطة والحصص والقيود الخاصة بهما. لا يوفّر NewsAPI نقطة `everything` فلترة دولة، وتُستخدم اللغة `all` هنا بعدم إرسال معامل اللغة. قد لا تتوفر نقطة Bing أو المفتاح في كل الاشتراكات؛ اضبط `endpoint` وفق الخدمة المتاحة لحسابك. يحتفظ البوت بفلترة العناوين الحالية لتقليل الأخبار غير المتعلقة بالسعودية.
